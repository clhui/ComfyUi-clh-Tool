# CLH 重复文件检查器节点

## 功能介绍

CLH 重复文件检查器是一个专为 ComfyUI 设计的自定义节点，用于检测指定目录下的重复大文件。该节点特别适用于管理 AI 模型文件，帮助用户清理重复的模型文件以节省磁盘空间。

## 主要特性

- 🔍 **智能扫描**: 支持扫描指定目录下的大文件（默认100MB以上）
- 🎯 **模型文件过滤**: 可选择仅扫描AI模型相关文件格式
- 🚀 **多线程处理**: 支持并行处理，提高扫描效率
- 📊 **详细报告**: 生成详细的重复文件报告，包含文件路径和可节省空间
- 🏠 **ComfyUI集成**: 自动检测ComfyUI根目录和常用模型目录
- 💾 **空间统计**: 计算重复文件占用的总空间

## 支持的文件格式

当启用"仅模型文件"选项时，节点会扫描以下格式的文件：

- `.ckpt` - Stable Diffusion checkpoints
- `.safetensors` - SafeTensors 格式
- `.pt`, `.pth` - PyTorch 模型
- `.bin` - 二进制模型文件
- `.pkl` - Pickle 文件
- `.h5` - HDF5 格式
- `.pb` - TensorFlow protobuf
- `.onnx` - ONNX 模型
- `.tflite` - TensorFlow Lite
- `.engine`, `.plan` - TensorRT 文件
- `.model`, `.weights` - 通用模型文件

## 节点参数

### 必需参数

- **scan_directory** (字符串): 要扫描的目录路径，默认为ComfyUI根目录
- **min_size_mb** (整数): 最小文件大小阈值(MB)，默认100MB
- **model_files_only** (布尔值): 是否只扫描模型文件，默认为True
- **max_workers** (整数): 最大并行线程数，默认4个线程

### 可选参数

- **preset_directory** (下拉选择): 预设目录选择，包含ComfyUI根目录和常用模型目录

## 输出结果

节点返回两个字符串输出：

1. **duplicate_report**: 详细的重复文件检查报告
2. **log_output**: 扫描过程的日志输出

## 使用方法

1. 在ComfyUI中添加"CLH 重复文件检查器"节点
2. 设置扫描目录（可使用预设目录或手动输入路径）
3. 调整最小文件大小阈值
4. 选择是否只扫描模型文件
5. 设置合适的线程数（建议4-8个线程）
6. 运行节点查看结果

## 使用建议

### 性能优化

- **线程数设置**: 对于SSD硬盘，可以设置较多线程(8-16)；对于机械硬盘，建议使用较少线程(2-4)
- **文件大小阈值**: 根据需要调整，较大的阈值可以减少扫描时间
- **目录选择**: 优先扫描特定的模型目录而非整个ComfyUI目录

### 安全提醒

- 节点只进行文件检测，不会自动删除任何文件
- 删除重复文件前请仔细检查报告，确保不会误删重要文件
- 建议先备份重要文件再进行清理操作

## 故障排除

### 常见问题

1. **"目录不存在"错误**: 检查输入的目录路径是否正确
2. **扫描速度慢**: 减少线程数或增加文件大小阈值
3. **内存占用高**: 减少线程数，特别是在处理大量文件时

### 性能监控

节点会在日志中显示：
- 扫描进度
- I/O处理速度
- 已处理的数据量
